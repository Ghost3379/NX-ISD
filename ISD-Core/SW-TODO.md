# ISD-Core Software Roadmap & Feature Specification

App concept:
- Vitals 
    |-> HRM
    |-> SpO2
    |-> MSF calculated Stress
    |-> settings for hrm measuring reminder
- Enviroment
    |-> Pressure
    |-> temperature
    |-> humidity
    |-> compass
    |-> Light intensity
    |-> MSF calculated weather info (forecast)
- Clock
    |-> Timer
    |-> stopwatch
    |-> worldclock
    |-> Alarms
    |-> Date, Time, & Timezone Settings
- Device
    |-> deeper Battery info, runtime, chargecycles, general heatlth and intel
    |-> NX-SDS
    |-> Storage
    |-> Firmware version and OTA updates via: https://nx-uplink.base44.app
- Tools
   |-> spirit level
   |-> NPM
   |-> ESP-Deauath
   |-> Wifi analysis
   |-> BLE analysis
   |-> connection to NX-Uplink
   |-> Oracle network integration (https://oracle-network.tech)
- Settings
   |-> notification (Buzzer, npm, which app? when? what? etc.)
   |-> Display (automatic dimining, manual dimming, tilt to wake)
   |-> Power safe mode (manual activation, automatic activation, settings on what should be effected)
   |-> Buzzer (intensity, volume etc, ON/OFF)
   |-> NX-AIS toggle
